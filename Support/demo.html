Pengaturan Support Widget

1. Atur di bawah  →  2. Klik Salin script  →  3. Tempel di website tujuan  ·  pengaturan tersimpan otomatis

Widget ditempel di atas tampilan websitemu. Pada posisi "Melayang", seret widget langsung di preview untuk mengatur posisinya. Posisi "di dalam halaman" final mengikuti letak <div id="support-widget"> di websitemu. Sebagian website menolak ditampilkan di preview (mis. Google, Facebook); itu batasan dari website tersebut.
