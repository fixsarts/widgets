Fixs Flip Clock

Widget jam flip untuk website mana pun. Satu file JS, tanpa dependensi.

Cara pasang

Untuk production, gunakan versi tetap atau cache-busting query string agar browser tidak memaksa cache URL lama.

<script src="https://cdn.jsdelivr.net/gh/fixsarts/widgets@v1.0.2/Flip%20Clock/flip-clock.js" defer></script>
<div data-fixs-flipclock data-theme="dark"></div>
