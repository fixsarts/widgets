Fixs Flip Clock

Widget jam flip untuk website mana pun. Satu file JS, tanpa dependensi.

Cara pasang

Tempel dua baris ini di website mana pun:

<script src="https://cdn.jsdelivr.net/gh/fixsarts/widgets@main/Flip%20Clock/flip-clock.js"></script>
<div data-fixs-flipclock data-theme="dark"></div>

Repo: github.com/fixsarts/widgets
