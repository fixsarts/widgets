Fixs Flip Clock

Widget jam flip untuk website mana pun. Satu file JS, tanpa dependensi.

Cara pasang

Tempel dua baris ini di website mana pun. Nama class wrapper bebas, yang wajib hanya atribut data-fixs-flipclock. Untuk kode sesuai pengaturan kamu, pakai kotak kode di Playground di bawah.

<script src="https://cdn.jsdelivr.net/gh/fixsarts/widgets@main/Flip%20Clock/flip-clock.js" defer></script>
<div data-fixs-flipclock data-theme="dark"></div>

Repo: github.com/fixsarts/widgets
